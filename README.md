# VSWM v0.3 prototype

Exploratory, uncalibrated simultaneous spatial memory task. Fixed 5x5 grid, 1500 ms exposure, 20 trials maximum. Rapid search then threshold sampling. Predetermined item bank; results downloaded locally as JSON. Do not interpret scores as norms or clinical measures.

Upload index.html, style.css, task.js and items.json to the GitHub Pages repository root.
